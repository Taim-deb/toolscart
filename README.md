# ToolScart

## Developer-first tools. Open source. Private by default.

ToolScart is a collection of fast, free, browser-based tools built to make everyday development work simpler.

Format data, encode and decode values, generate identifiers, test regular expressions, create CSS snippets, and more, without signing in or switching between multiple websites.

[Visit ToolScart](https://toolscart.org)

## Why ToolScart?

- No sign-in required
- No tracking
- No cookies
- No ads
- No data collection
- No third-party processing services
- Tools run directly in your browser
- Free and open source

Google Fonts is used as the only external resource for typography.

## Available Tools

### JSON & Data

- [JSON Formatter](https://toolscart.org/tools/json-formatter/) - Format and beautify JSON
- [JSON Validator](https://toolscart.org/tools/json-validator/) - Check JSON for syntax errors
- [JSON Minifier](https://toolscart.org/tools/json-minifier/) - Compress JSON by removing whitespace
- [JSON to CSV Converter](https://toolscart.org/tools/json-csv/) - Convert JSON data into CSV format

### Encoding & Security

- [Base64 Encoder & Decoder](https://toolscart.org/tools/base64/) - Encode and decode Base64 text
- [URL Encoder & Decoder](https://toolscart.org/tools/url-encoder/) - Encode and decode URL components
- [JWT Decoder](https://toolscart.org/tools/jwt-decoder/) - Decode JSON Web Token headers and payloads
- [HTML Entity Encoder & Decoder](https://toolscart.org/tools/html-entity/) - Convert HTML entities and special characters
- [UUID Generator](https://toolscart.org/tools/uuid-generator/) - Generate UUID version 4 identifiers
- [Hash Generator](https://toolscart.org/tools/hash-generator/) - Generate MD5 and SHA-256 hashes

### Developer Utilities

- [Regex Tester](https://toolscart.org/tools/regex-tester/) - Test regular expressions against text
- [Timestamp Converter](https://toolscart.org/tools/timestamp-converter/) - Convert Unix timestamps and dates
- [Cron Generator](https://toolscart.org/tools/cron-generator/) - Create and understand cron expressions
- [Slug Generator](https://toolscart.org/tools/slug-generator/) - Generate URL-friendly slugs

### CSS Tools

- [CSS Gradient Generator](https://toolscart.org/tools/css-gradient/) - Create CSS gradients
- [CSS Box Shadow Generator](https://toolscart.org/tools/css-box-shadow/) - Generate CSS box-shadow styles
- [CSS Border Radius Generator](https://toolscart.org/tools/css-border-radius/) - Create CSS border-radius styles

### Formatting & Preview

- [Markdown Preview](https://toolscart.org/tools/markdown-preview/) - Preview rendered Markdown
- [HTML Formatter](https://toolscart.org/tools/html-formatter/) - Format and beautify HTML
- [CSS Formatter](https://toolscart.org/tools/css-formatter/) - Format and beautify CSS
- [JavaScript Formatter](https://toolscart.org/tools/javascript-formatter/) - Format and beautify JavaScript
- [SQL Formatter](https://toolscart.org/tools/sql-formatter/) - Format and beautify SQL queries

## Privacy

ToolScart is designed to be useful without collecting personal information.

You do not need an account to use the tools. ToolScart does not use tracking, analytics, advertising cookies, or third-party processing services. Tool inputs are processed locally in your browser and are not intentionally sent to or stored on external servers.

For more information, see the [Privacy Policy](https://toolscart.org/privacy.html).

## Open Source

ToolScart is open source and welcomes contributions from developers.

If you find a bug, have an idea, or want to add a new tool, feel free to open an issue or submit a pull request.

## Contributing

1. Fork the repository.
2. Create a branch for your change.
3. Make your changes.
4. Test the tool locally.
5. Open a pull request with a clear description.

Please keep new tools fast, accessible, easy to use, and consistent with the privacy-first principles of ToolScart.
